# SQL Data Transformer

Project Overview
SQL Data Transformer is a beginner-friendly SQL project created to practice data analysis and data transformation using MySQL.

objectives
- Understand database and table creation.
- Combine data from multiple tables.
- Retrieve and transform data using SQL queries.
- Practice important SQL concepts used in data analysis.

 Tools Used
- MySQL
- MySQL Workbench
- SQL

 Database Tables
- **Customers:** Stores customer information.
- **Orders:** Stores order details.
- **Employees:** Stores employee information.

 SQL Concepts Covered
- **JOINs:** Combine data from multiple tables.
- **Subqueries:** Retrieve data using nested queries.
- **Date Functions:** Work with dates.
- **String Functions:** Format and manipulate text.
- **Window Functions:** Calculate rankings and running totals.
- **CASE Statements:** Apply conditions and categorize data.

How to Run
1. Open MySQL Workbench.
2. Create or select the `data_transformer` database.
3. Execute the SQL table creation statements.
4. Insert the sample data.
5. Run the SQL queries one by one.
6. Review the output of each query.

 Learning Outcomes
- Improved understanding of SQL queries.
- Learned how to combine and analyze data.
- Practiced data transformation techniques.
- Developed foundational skills for data analyst projects.
